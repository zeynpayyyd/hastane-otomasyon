# 🏥 Hastane Randevu Sistemi

Bu proje, hastane randevu süreçlerini dijital ortamda yönetmek amacıyla geliştirilmiş web tabanlı bir hastane randevu sistemidir.

## 🚀 Proje Hakkında

Sistem; kullanıcıların hastane randevularını oluşturabilmesi, mevcut randevuları görüntüleyebilmesi ve gerektiğinde randevuları iptal edebilmesi için geliştirilmiştir.

Verilerin yönetimi ve saklanması için **Supabase** altyapısından yararlanılmıştır.

## 🛠️ Kullanılan Teknolojiler

* **HTML5** – Web sayfasının yapısının oluşturulması
* **CSS3** – Arayüz ve kullanıcı deneyiminin tasarlanması
* **JavaScript** – Dinamik işlemlerin gerçekleştirilmesi
* **Supabase** – Veritabanı ve veri yönetimi

## ✨ Temel Özellikler

* 📅 Hastane randevusu oluşturma
* 📋 Randevuları listeleme
* ❌ Randevu iptal etme
* 🏥 Branş seçimi
* 👨‍⚕️ Doktor/randevu bilgilerinin yönetimi
* 💾 Supabase üzerinden veri saklama
* 📱 Kullanıcı dostu web arayüzü

## 🎯 Projenin Amacı

Hastane randevu işlemlerini daha düzenli ve erişilebilir hale getirmek, randevu bilgilerinin dijital ortamda yönetilmesini sağlamak ve temel hastane otomasyon süreçlerine yönelik bir web uygulaması geliştirmektir.
